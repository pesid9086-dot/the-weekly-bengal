Build a complete, production-grade, and aesthetically elite Bengali News Portal web application named "The Weekly Bengal" using React, TypeScript, Tailwind CSS, Lucide React icons, and Wouter for routing.

================================================================================
1. ZERO-BREAKAGE ARCHITECTURAL RULES (CRITICAL FOR VERCEL & REPLIT)
================================================================================
- NO EXTERNAL SUPABASE SDK: Strictly DO NOT install or import `@supabase/supabase-js`. This prevents Rollup bundling, node-builtins, and package resolution errors.
- DIRECT REST API ONLY: All database operations must use standard browser `fetch()` calling Supabase REST endpoints using `import.meta.env.VITE_SUPABASE_URL` and `import.meta.env.VITE_SUPABASE_ANON_KEY`.
- REFRESH 404 REWRITE FIX: Provide a repository root `vercel.json` file with:
  {
    "rewrites": [
      { "source": "/(.*)", "destination": "/index.html" }
    ]
  }
- ONLY ONE SUPABASE TABLE: The entire application requires only ONE table named `news` in public schema:
  Columns:
  * `id` (bigint or uuid, primary key)
  * `title` (text, not null)
  * `content` (text, not null)
  * `category` (text, not null)
  * `image_url` (text)
  * `status` (text: 'published' | 'pending')
  * `author_name` (text)
  * `author_id` (text)
  * `created_at` (timestamp with time zone)
- Fallback & Offline Resilience: If Supabase connection fails or returns empty, the app must fall back seamlessly to an in-memory / localStorage dataset so the site never looks blank.
